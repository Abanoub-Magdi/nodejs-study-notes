# Node.js Study Notes

My Node.js learning journal. These interactive guides are written in Arabic and run offline in a browser.

## Study sessions

- [The Node.js event loop](nodejs-event-loop-study.html) covers blocking and non-blocking code, the worker pool, and when callbacks run. It includes a simulation, review cards, and a quiz.
- [Node.js modules](nodejs-modules-arabic-guide.html) shows how to split an HTTP server into separate files with `require` and `module.exports`. It covers module caching and includes a quiz.

Download or clone the repository and open either HTML file in your browser. The pages do not require a build step or a local server.
